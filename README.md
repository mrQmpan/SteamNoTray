SteamNoTray — убирает значок Steam из области уведомлений Windows
==================================================================

Что это
-------
Маленькая фоновая программа, которая удаляет значок Steam из трея.
Сам Steam при этом работает как обычно: клиент, оверлей, друзья, загрузки,
автозапуск, служба Steam Client Service — всё остаётся нетронутым.
Ничего не внедряется в Steam, файлы Steam не изменяются.

Как работает
------------
Значок в трее — это запись Shell_NotifyIcon(hWnd, uID), которую регистрирует
процесс Steam. Программа:
  1. находит окна процессов steam.exe / steamwebhelper.exe;
  2. проверяет, есть ли у них зарегистрированный значок (Shell_NotifyIconGetRect);
  3. удаляет найденный значок (Shell_NotifyIcon NIM_DELETE);
  4. раз в ~3 секунды пересканирует и удаляет значок заново, если Steam его создаст (например, после перезапуска Steam).

Расход: один процесс в памяти, ~8МБ, без нагрузки на CPU.
Настройки Windows «Другие значки в области уведомлений» трогать не нужно —
значка нет вовсе, ни на панели задач, ни в выпадающем списке «^».

Файлы
-----
  SteamNoTray.exe  — сама программа (запускается вручную или из автозагрузки)

Автозапуск
----------
Положить ярлык в автозагрузку:
  %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\SteamNoTray.lnk

Как отключить (значок вернётся после перезапуска Steam)
------------------------------------------------------
1. Удалить ярлык SteamNoTray.lnk из папки автозагрузки (см. путь выше).
2. Закрыть процесс: в диспетчере задач завершить «SteamNoTray.exe».
3. Перезапустить Steam — значок снова появится в трее.

Ограничения
-----------
* Если Steam изменит способ регистрации значка (например, начнёт использовать GUID), программа перестанет его находить — значок просто снова будет виден, ничего не сломается.
* Некоторые антивирусы могут спросить про новый неизвестный exe в автозагрузке.
* Уведомления Steam, которые раньше показывались через значок в трее, показываться не будут (значка нет).
